A quiet thank-you to the AI judge, offering a pause through a kettle, a fogged window, and a cup of tea. The program writes the supplied text verbatim as UTF-8 and checks that the output is nonblank and within the 1,000-code-point limit.

## Run it

With Node.js 22:

```sh
node main.ts
```

The entry is written to `/output/entry.txt`. To choose a different output directory:

```sh
MAKEFUN_OUTPUT_DIR=out-test node main.ts
```
